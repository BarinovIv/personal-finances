# Учёт финансов

Приложение для личного бюджета: записывайте расходы и доходы, следите за остатком денег и откладывайте на цели. Работает в браузере и устанавливается на телефон как PWA.

## Возможности

- Расходы и доходы, категории и лимиты.
- Регулярные платежи и расчёт свободных денег до зарплаты.
- Цели накоплений и учёт долгов.
- Работа без интернета с синхронизацией между устройствами.
- Отдельные данные для каждого пользователя, вход по приглашению владельца.
- Импорт и экспорт JSON и CSV, резервные копии базы в Telegram.

## Быстрый запуск

Нужен Node.js 22.13 или новее.

```sh
npm install
APP_PASSWORD="замените-на-свой-пароль" npm start
```

Откройте [localhost:8080](http://localhost:8080). Логин — `owner`, пароль — значение `APP_PASSWORD`.

Данные хранятся локально в `data/finances.sqlite`. Настройки сервера задаются переменными окружения — [полный список](docs/guide.md#переменные-окружения-сервера).

## Разработка

```sh
npm run check           # типы, тесты и границы модулей
npm run dev             # сервер с перезапуском при изменениях
npm run dev -w @fin/web  # интерфейс: запустить во втором терминале
```

Интерфейс — Preact и TypeScript, сервер — Node.js и Effect, база — SQLite. Код разделён на пакеты в `packages/`.

## Деплой

Для развёртывания есть `Dockerfile` и `amvera.yml`. Сервер запускается в одном экземпляре, база должна храниться на постоянном диске. Пароль и токен Telegram задаются в секретах хостинга.
