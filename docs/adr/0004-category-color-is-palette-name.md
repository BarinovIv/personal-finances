# Цвет категории хранится названием из палитры, а не hex

Раньше в категории хранился произвольный hex. Из-за этого тёмные приглушённые цвета терялись в тёмной теме, а смена палитры не затрагивала уже изменённые категории. Теперь в категории хранится название цвета из фиксированной палитры (`green`, `orange`, `indigo`…), а конкретный оттенок для светлой и тёмной темы подставляет приложение. Цена решения: палитра становится частью формата записей и синхронизации. Убрать цвет из палитры нельзя, не сопоставив его с другим, а старые hex-значения при чтении сопоставляются с ближайшим названием.
