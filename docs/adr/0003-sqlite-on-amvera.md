# SQLite-файл на диске Amvera вместо управляемой базы данных

Нужен российский хостинг с оплатой в рублях. Выбран Amvera (тариф Starter, около 290 ₽/мес): одно Node-приложение отдаёт и PWA, и API. Данные лежат в SQLite-файле на постоянном диске Amvera. Управляемый PostgreSQL стоил бы ещё около 290 ₽/мес и потребовал бы сетевого доступа к отдельной базе. При одном пользователе и одном экземпляре сервера это не даёт ничего.

## Consequences

- Сервер должен работать в одном экземпляре: SQLite не разделяется между репликами.
- Резервные копии — сервер сам каждую ночь шлёт снимок базы в Telegram, плюс выгрузка в CSV из приложения. Бэкапы Amvera есть только с тарифа «Начальный Плюс» и хранятся два дня, поэтому на них не полагаемся.
- Если понадобится несколько экземпляров или другой хостинг, переезд на PostgreSQL затронет только адаптер хранилища на сервере.
