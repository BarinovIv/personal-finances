# Регулярные операции создаёт сервер, а не клиент

Операции по регулярным шаблонам мог бы создавать и клиент при открытии приложения. Но с двумя устройствами офлайн это даёт дубли. Поэтому их создаёт только сервер: раз в сутки по московскому времени и при старте, догоняя всё пропущенное. У каждой такой операции детерминированный идентификатор (шаблон + месяц), так что повторный запуск ничего не задваивает. Клиент получает операции обычной синхронизацией, а «предстоящие списания» считает сам по шаблонам, поэтому они видны и офлайн.
