# Проверка задач #42–#50

Дата: 2026-10-05. Локальный сервер с отдельной SQLite-базой и синтетическими данными; рабочая база не использовалась.

`npm run check`: 41 файл, 452 теста; typecheck и проверка зависимостей прошли. `npm run build` прошёл.

## Автоматические регрессии

- Разбор точного примера #45: пять расходов 200, 200, 200, 500, 100, всего 1200. Соседние суммы, компактные и разделённые пробелами операторы, тысячи, даты, доходы и описания "24/7". Ошибочный пакет отклоняется целиком с правильным индексом.
- Таймаут `/api/me` на 3000 мс охватывает запрос и чтение тела. Поздние ответы 200/401/410 после смены сессии не меняют текущего пользователя и очередь.
- Фоновый обмен ограничен 30 секундами; вход и выход отменяют незавершённый обмен. Повтор после потерянного ответа не создаёт дубликат принятой операции.
- Существующие проверки редактирования, возвратов, отмены, обучения категорий и лимитов прошли.

## Уточнения интерфейса после отката релиза

- Крупные заголовки имеют верхний отступ 20 px; шапки вложенных страниц — 16 px с учётом safe area.
- Действия выровнены по вертикальному центру всего блока заголовка, включая подпись суммы. Playwriter проверил ширины 320, 390, 560 и 1280 px, отсутствие пересечений и работу единственной кнопки поиска в закреплённой шапке. Длинный статус "ждёт сети" проверен на ширине 320 px в светлой и тёмной темах; блоки сохраняют выравнивание и не пересекаются.
- У системных эмодзи убраны цветной круг и тень, в выборе иконки выделение обозначено квадратной рамкой со скруглением. Служебные SVG сохраняют прежнее оформление.
- У редактируемых суммы и описания добавлены спокойные значки карандаша. Нажатие на каждый значок фокусирует соответствующее поле; проверены изменение черновика и доступность галочки сохранения.

Typecheck, production build и проверка зависимостей прошли. Дополнительное ревью семи изменённых файлов не выявило регрессий. Проверки выполнялись локально через Playwriter, без публикации изменений.

У описания используется простой контурный карандаш без квадратной рамки. Он расположен сразу за текстом, рядом с ним, а не у правого края экрана. После изменения проверено в Playwriter: ширина текстового блока подстраивается под описание, сохранено центрирование карточки; нажатие на значок фокусирует поле.
